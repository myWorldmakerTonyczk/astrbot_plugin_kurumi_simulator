# 用户面板与 AI 复盘

后台选择实例后，在「AI 复盘」里查看成交标记、净值、收益率和回撤。两条图共享时间轴，点成交或时间线可看当时理由、相关操作、历史策略和日记。早于升级的成交和日志仍可查，净值曲线从升级后实际采样开始。账户回撤基于资金流调整后的收益指数。复盘按单一品种展示成交，账户曲线覆盖整个实例。

## 聊天里查看

请在已绑定的私聊中向机器人提出需求，例如「发我今天的回撤图」「看一下过去一周 EUR/USD 的成交」。可发 K 线与成交、净值、收益率、回撤、看盘活动、累计平仓盈亏扣成交费、单笔平仓盈亏和成交手续费。图片生成不依赖独立网页服务。系统有中文字体时使用中文图例，否则使用英文图例。

在实例的「用户网页权限」里可以指定领取入口的私聊 UMO，每行一个。原来只用随机 ID 创建的实例，可用这个设置绑定领取私聊。填了专用名单后，只允许名单内的私聊领取。改动名单会撤销该用户的网页凭据和现有链接。留空则沿用已有 QQ 或 UMO 绑定。

网页启用后，也可在获授权的私聊中说：

- 「给我本人只读面板」查看自己的曲线、策略和日记。
- 「给我一条复盘摘要分享链接」只分享图表及成交，不带策略和日记。
- 「给我登录操作面板」领取自己的账号和首次密码。首次密码仅通过私聊发送，后续领取只发送账号和入口。忘记密码时请管理员重置后重新领取。

临时链接 5 分钟内只能兑换一次，浏览器只读会话有效 1 小时。账号登录有效 8 小时。通过网页登录后可切换自己的实例，管理员为某个实例开启「允许该用户在网页模拟交易」后，才能开仓、平仓和调整止损止盈。后台的「用户网页权限」支持撤销本实例的链接会话及重置该用户账号。

## 在现有服务器启用

在 AstrBot 插件页面的「设置 → 用户面板」填写独立 HTTPS 域名，如 `https://panel.example.com`。插件使用单独监听端口，默认 `8791`。用户访问这个域名，AstrBot 管理后台继续使用原地址。

AstrBot 原生运行时可选监听 `127.0.0.1`，由同机 HTTPS 反向代理转发。AstrBot 跑在 Docker 中、代理在宿主机时，面板选容器网络 `0.0.0.0`，给容器添加本机端口映射 `127.0.0.1:8791:8791`。如果代理也在 Docker 里，可让两者共用内部网络，直接代理到 AstrBot 容器的 8791 端口。

独立域名对应的 Nginx HTTPS server 配置中，添加：

```nginx
location / {
    proxy_pass http://127.0.0.1:8791;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

插件按配置的域名校验 Host 和写操作 Origin。代理应保留浏览器访问的 Host，并在代理上配置证书。启用后先打开域名确认出现用户登录页，再从绑定私聊领取入口。
