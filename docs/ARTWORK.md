# 视图配图

来源：用户提供的七张久留美参考图。处理方式：内置 imagegen 编辑，保留角色识别特征和二维画风，清理截图水印/表情叠字、改善压缩痕迹；生成式修复会存在局部画法变化，不声称逐像素还原。

文件位于 views/dashboard/assets：

- avatar.png：参考第7张，眨眼头像，方形头肩构图。
- hero-red.png：参考第3张，清理右下角上传者水印，保留红光和表情，作为正收益横幅。
- hero-green.png：参考第4张，清理右下角上传者水印，保留绿光和表情，作为负收益横幅。
- neutral.png：参考第2张，提升压缩截图清晰度，作为中性／等待行情横幅。
- laugh.png：参考第1张，清理覆盖的表情文字与底部小字，作为记忆页面装饰。
- distress.png：参考第5张，清理覆盖的表情文字与底部小字，作为连接失败提示配图。
- welcome.png：参考第6张，取头肩、手机和K线背景，清理海报文字，作为欢迎页配图。

编辑提示词共同约束：保留确切角色、粉色短发、原有表情与二维动画线条；不改成真人或3D，不新增人物、标志或文字；只在必要的水印区域修复背景。红／绿图保留原光照，头像保留眨眼与发夹，欢迎图只取头肩。

配图均随插件打包；未使用外部图片CDN，不需要用户额外配置。配图为用户提供内容的AI修复版本，非官方产品标识。
